01 关于我

我是一名 AI产品经理，日常与 AI Agent、提示词工程、 自动化工作流打交道，关注大模型能力如何真正落地为产品价值。

我特别着迷于「产品拆解」这件事：不是看宣传页，而是打开产品、 逐条浏览真实操作记录，梳理出从输入需求到最终产出的完整用户旅程， 再判断哪些体验是好的、哪些是断裂的。

我的方法强调「证据优先」：所有结论分为页面事实、 合理推断与尚未确认三类，避免用常识和宣传语脑补产品。

同时，我把拆解能力沉淀为可复用的 Skill 与 Agent 工作流， 让「看懂一个产品」变成一套可持续运转的系统，而非一次性手工作业。

用户旅程图

/ 03

Agent 工作流设计

设计高质量提示词与 Skill，面向 AI 产品经理的专业内容创作。

/ 05

知识库沉淀
