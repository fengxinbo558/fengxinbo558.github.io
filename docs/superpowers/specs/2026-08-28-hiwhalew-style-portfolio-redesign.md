# 冯新波个人主页桌面系统风格改版设计

## 目标

将现有 `fengxinbo558.github.io` 从黑白点阵风长页面，改造成与 `hiwhalew.github.io` 高度一致的“桌面操作系统”式单页个人主页。页面的空间结构、视觉比例、导航方式、窗口质感、启动动画和主要交互尽量高保真复刻；所有姓名、文案、头像、文章、项目与外链使用冯新波现有内容，不沿用参考站作者的个人素材。

页面的唯一任务是：让访客在一个屏幕内快速认识冯新波的定位，并能进入项目、文章和联系方式。

## 实施边界

- 采用独立编写的 HTML、CSS 和 JavaScript，不复制参考站的编译产物。
- 保持 GitHub Pages 可直接托管，不引入构建步骤或运行时依赖。
- 继续使用仓库内的 `avatar.svg`，将它置入参考站同类的悬挂证件卡造型。
- 只使用目标站已有且可验证的项目、文章和社交链接，不虚构经历、指标、客户或联系方式。
- 删除 `you@example.com` 占位邮箱；在用户未提供真实邮箱前，联系页只展示 GitHub 和公众号。
- 不复制参考站作者的肖像、文章封面或其他个人资产。

## 视觉与布局

### 整体框架

页面由两个连续状态组成：

1. 全屏终端启动页：浅灰系统背景、等宽字体、逐行启动信息、闪烁光标和“进入工作台”入口。
2. 桌面工作台：顶部系统标识、左侧导航、中央 macOS 风格窗口和底部状态栏。

桌面端主要布局固定在一个视口内，中央窗口承担全部内容切换。手机端改为自然纵向滚动：导航横向排列，窗口内容垂直堆叠，避免缩小桌面布局导致阅读困难。

## 组件与职责

- `TerminalIntro`：负责启动文本、跳过/进入和减少动态效果分支。
- `DesktopShell`：负责系统顶部、导航、中央窗口和底部状态。
- `SidebarNav`：维护 ABOUT、WORK、NOTES、CONTACT 当前视图与无障碍状态。
- `AboutView`：身份信息、头像卡和决策系统。
- `WorkView`：项目列表与选中详情。
- `NotesView`：文章卡片和外链。
- `ContactView`：联系渠道。
- `MotionController`：集中处理启动动画、切页动画、头像拖拽和减少动态效果。

实现仍可保留为三个静态文件，但 JavaScript 按上述职责分区，避免把状态切换、拖拽和动画混在一个不可维护的流程中。

## 交互与状态流

页面加载后先进入 `booting`，启动信息完成后进入 `ready`，用户确认后进入 `workspace`。工作台只维护一个 `activeView`，导航切换时替换中央窗口内容并更新标题路径。

项目区另维护 `activeProject`，决策图另维护 `activeLane`。它们互不影响，离开视图再返回时保留本次访问中的选中状态。

头像拖拽使用 Pointer Events，同时支持鼠标、触摸和触控笔。拖拽范围限制在 ABOUT 主窗口附近，避免卡片被拖出视口或遮挡导航；视图切换时恢复安全位置。

## 异常与降级

- 字体加载失败时使用系统字体，布局不能依赖特定字体宽度。
- JavaScript 执行失败时，页面至少显示 ABOUT、项目、文章与联系方式的静态内容，不停留在不可关闭的启动遮罩。
- 头像加载失败时显示姓名缩写占位卡。
- 外部链接统一使用 `target="_blank"` 和 `rel="noopener"`。
- 不支持 `backdrop-filter` 时使用不透明白色窗口背景。
- 窄屏、矮屏和横屏手机都有独立布局，内容不得被固定视口裁切。

## 无障碍

- 所有导航和选择控件使用原生按钮或链接。
- 当前导航项使用 `aria-current`，可切换项目与决策路径使用明确的选中状态。
- Enter、Space 和方向键可完成核心操作。
- 提供明显的键盘焦点样式。
- 遵循 `prefers-reduced-motion`，关闭逐字、摆动、回弹和大幅切换动画。
- 颜色对比满足正文可读性，不能只靠颜色表达选中状态。

## 验证标准

- 桌面端首次进入、终端启动、四个视图切换、项目选择、决策路径切换和所有外链均可用。
- 1440×900、1024×768、390×844 三个视口无水平溢出、文字遮挡或不可达内容。
- JavaScript 控制台无错误。
- 键盘可进入工作台并遍历所有导航和主要操作。
- 开启减少动态效果后不出现强制等待和持续动画。
- 页面所有姓名、介绍、项目、文章和联系链接均属于冯新波；不存在俞婧雯或参考站的个人内容。
- GitHub Pages 仍可直接从仓库根目录发布。
